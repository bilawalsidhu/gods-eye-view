- Let self-hosters point the OpenFreeMap vector tile source at their own tile
  server. The new optional `OPENFREEMAP_TILEJSON_URL` (an `https` URL or a path
  on the app's own origin) is read like `PHOTON_URL` and reaches Street Traffic,
  Mapped Installations and voice outlines. Unset keeps the public address, and
  an invalid value stops the dev server and the build with an error naming the
  variable (daika, #1671).
