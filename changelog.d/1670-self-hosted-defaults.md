- Let an operator serve the keyless basemap from their own tile server:
  `GEV_BASEMAP_URL` takes an https XYZ template that replaces Esri World
  Imagery, with `GEV_BASEMAP_ATTRIBUTION` for its credit. The map tile reads
  "Basemap", keeps the `esri-imagery` share-link id, and never falls back to
  OSM; an invalid value stops the server at startup. Unset, Esri stays the
  default (daika, #1670).
- Let an operator choose the keyless terrain: `GEV_TERRAIN_URL` takes an https
  quantized-mesh URL in place of Re:Earth, or `none` for flat terrain with no
  terrain requests. Once it is set, the `/api/terrain/heights` proxy contacts
  no upstream and the page places objects on its bundled geoid. Unset,
  Re:Earth stays the default (daika, #1670).
- Serve the interface fonts from the app itself: Inter, JetBrains Mono, Noto
  Sans Arabic and Hebrew, and the Material Symbols icon subset are bundled
  under `public/fonts/` with their licences, regenerated by
  `scripts/vendor-fonts.mjs`. Loading the page no longer contacts
  fonts.googleapis.com or fonts.gstatic.com, and the CSP drops both hosts
  (daika, #1670).
