# Small original planetary overview textures

These files are original downloaded JPEG bytes, not generated or edited images.
`manifest.json` records source URLs/pages, credits, usage-policy links, retrieval
date, dimensions, byte sizes and SHA-256 hashes. Total JPEG bytes: 1,430,838.

- `moon.jpg`: NASA SVS CGI Moon Kit's 2025 low-resolution color map (2048×1024).
  Credit NASA/GSFC/SVS, Ernie Wright; LRO/LROC/LOLA teams.
- `mars.jpg`: NASA Mars image texture (1440×720), based on Viking images processed
  at USGS. Credit Courtesy NASA/JPL-Caltech.

The MIT code license does not relicense these images. Retain source credits and
captions under [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/)
and [JPL's image-use policy](https://www.jpl.nasa.gov/jpl-image-use-policy/).
There are no NASA/JPL logos or claims of endorsement in this pack.

These are coarse processed display maps with no attached DEM. The Moon map has
filled/inpainted polar areas and is explicitly optimized for visualization.
Use original scientific products and coordinate metadata for quantitative work.
