# Moscow camera groups

The runtime reads [../cctv_sources.moscow.json](../cctv_sources.moscow.json). These files classify the 100 active cameras without adding category prefixes beyond their short English labels. RC means residential complex.

1. [Residential complexes and developers](01-developers.json): 87 active cameras.
2. [Streets and panoramas](03-urban-views.json): 8 active cameras.
3. [Outdoor sports](04-parks-sports.json): 5 active cameras.

See [verification and usage notes](../../docs/MOSCOW_100_CAMERAS.md).
