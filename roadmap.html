Princípios de qualidade

Sem telas falsas: botões e controles só são anunciados como funcionais após teste. Sem dados inventados: simulações devem ser rotuladas. Privacidade: GPS somente com consentimento, favoritos locais por padrão. Segurança: não expor servidores de desenvolvimento, credenciais ou endpoints MCP à internet sem autenticação e revisão. Licenças: respeitar as fontes e autores originais.

Este roadmap é um documento de planejamento. Os módulos marcados como “Parcial” possuem apenas componentes iniciais; não representam funcionalidades completas. Nenhuma data de lançamento é garantida.

Como contribuir

Experimente as branches públicas, registre problemas reproduzíveis, sugira fontes de dados legais e contribua com traduções, testes e documentação. Pull Requests devem preservar atribuições e licenças de terceiros.
