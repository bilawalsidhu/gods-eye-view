# Military plugin — test proof

- Plugin id: `military` — **OnDemand Spatial Military Flights (adsb.lol /v2/mil)** (category Research)
- Module: `server/tools/military.js` (reuses `server/providers/aircraft/adsb-lol.js` in-process via `server/tools/_invoke.js`; readsb normaliser shared with `server/tools/flights.js`)
- Recorded: **2026-09-18T16:34:10Z** (UTC)

## Tools

| Tool | Params | cacheSeconds |
| --- | --- | --- |
| `military_flights_in_bbox` | `lat`\* (−90..90), `lon`\* (−180..180), `radiusNm` (10..1500, default 600), `lamin`/`lomin`/`lamax`/`lomax` (optional; all four → bounding-box filter — the proxy radius is widened to cover the box corners), `limit` (1..1000, default 200) | 12 |

Calls `/api/adsblol/mil?lat=&lon=&radiusNm=` (adsb.lol `/v2/mil` → adsb.fi → last-good, scene-filtered server-side) and normalises each readsb row to `{ icao24, callsign, registration, type, description, category, lat, lon, onGround, baroAltFt, geoAltFt, groundSpeedKt, trackDeg, verticalRateFpm, squawk, emergency, seenSec, seenPosSec, lastSeenUtc, military, interesting, pia, ladd, distanceNm }`, nearest first, capped by `limit`; `data` = `{ scene, sourceFeed, coverage (X-Flight-Coverage), snapshotUtc, count, total, aircraft }`, `provider` = the proxy's X-Provider-\* status (live / stale / degraded; HTTP 503 `upstream_unavailable` when no feed can answer).

## Unit tests

```
node --test src/tooling/toolsMilitary.test.mjs
# tests 7  pass 7  fail 0
```

Covered (network fully mocked with `t.mock.method(globalThis, 'fetch', …)`, clock pinned, `AIRPLANES_LIVE_ENABLED` unset): descriptor; `radiusCoveringBbox` reaches every corner and is capped at the proxy ceiling; happy path through the **registered tool + tools route + real adsb.lol proxy** (live, `s-maxage=12`, the 880 nm / European / positionless rows are filtered out at 600 nm, `provider.count` is the scene count, a second scene within 12 s is a cache HIT, 1500 nm reaches the far row nearest-first); an explicit bbox widens the requested radius and filters rows to the box; degraded propagation (adsb.lol 503 → adsb.fi → `provider.status = degraded`, `sourceFeed = adsb.fi`); every feed down → structured 503 `upstream_unavailable` (handler and HTTP envelope); 400 `unknown_param` / `invalid_param` / `missing_param` through `createToolsHandler({ index: toolIndex() })` with fetch forbidden; and `JSON.stringify(result)` never contains the fake `ONDEMAND_API_KEY` set for the test process.

`node scripts/format.mjs --check` and `npm run check:boundaries` pass; `node scripts/generate-tool-openapi.mjs --server https://example.invalid` emits `docs/plugins/military/openapi.json` with 1 operation (regenerated by the orchestrator with the preview URL).
