# Flights plugin — test proof

- Plugin id: `flights` — **OnDemand Spatial Live Flights (OpenSky → adsb.lol → adsb.fi)** (category Research)
- Module: `server/tools/flights.js` (`flights_in_bbox` reuses `server/providers/aircraft/opensky.js` in-process via `server/tools/_invoke.js`; `flight_by_icao24` uses `fetchUpstreamJson` from `server/providers/common/upstream.js`)
- Recorded: **2026-09-18T16:34:10Z** (UTC)

## Tools

| Tool | Params | cacheSeconds |
| --- | --- | --- |
| `flights_in_bbox` | `lat`\* (−90..90), `lon`\* (−180..180), `radiusNm` (5..250, default 150), `lamin`/`lomin`/`lamax`/`lomax` (optional; all four → bounding-box filter instead of the radius), `limit` (1..1000, default 200), `onGround` (boolean, default false = airborne only) | 10 |
| `flight_by_icao24` | `icao24`\* (string, `/^[0-9a-f]{6}$/i`) | 10 |

`flights_in_bbox` normalises OpenSky state vectors (icao24, callsign, origin_country, time_position, last_contact, longitude, latitude, baro_altitude, on_ground, velocity, true_track, vertical_rate, sensors, geo_altitude, squawk, spi, position_source) to `{ icao24, callsign, originCountry, lat, lon, baroAltM, geoAltM, velocityMs, headingDeg, verticalRateMs, onGround, squawk, positionUtc, lastContactUtc, distanceNm }`, sorted nearest-first; `sourceFeed` = `X-Flight-Source`, `coverage` = `X-Flight-Coverage`, `provider` = the proxy's X-Provider-\* status (live / stale / degraded; HTTP 503 `upstream_unavailable` when nothing can answer). `flight_by_icao24` tries `https://api.adsb.lol/v2/hex/{hex}` (10 s, 1 retry) then `https://opendata.adsb.fi/api/v2/hex/{hex}` and normalises the readsb row to `{ icao24, callsign, registration, type, description, lat, lon, baroAltFt, geoAltFt, groundSpeedKt, trackDeg, verticalRateFpm, squawk, seenSec, military: Boolean(dbFlags & 1), … }`; not tracked → 404 `not_found`; both feeds down → 503 with `provider.status = unavailable`.

## Unit tests

```
node --test src/tooling/toolsFlights.test.mjs
# tests 7  pass 7  fail 0
```

Covered (network fully mocked with `t.mock.method(globalThis, 'fetch', …)`, `OPENSKY_AUTH_MODE=anon`, clock pinned): OpenSky-state and readsb normalisers; happy path through the **registered tool + tools route + real OpenSky proxy** (live, `s-maxage=10`, ground / out-of-radius rows excluded, cache HIT on the second call, bbox filter replaces the radius, limit caps the array); degraded propagation (OpenSky connect timeout → adsb.lol regional feed → `provider.status = degraded`, `sourceFeed = adsb.lol`); every feed down → structured 503 `upstream_unavailable` (handler and HTTP envelope); `flight_by_icao24` adsb.lol hit → adsb.fi fall-back (`degraded`, one retry on the 5xx) → 404 `not_found` → 503 `unavailable`; 400 `unknown_param` / `invalid_param` / `missing_param` through `createToolsHandler({ index: toolIndex() })` with fetch forbidden; and `JSON.stringify(result)` never contains the fake `ONDEMAND_API_KEY` set for the test process.

`node scripts/format.mjs --check` and `npm run check:boundaries` pass; `node scripts/generate-tool-openapi.mjs --server https://example.invalid` emits `docs/plugins/flights/openapi.json` with 2 operations (regenerated by the orchestrator with the preview URL).
