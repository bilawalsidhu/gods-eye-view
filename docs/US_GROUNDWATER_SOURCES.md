# Sources for the public 50-state Water Wells release

This list matches immutable public release `e6dc61db1500b491671cf094602e2257814c5507e99618d717fbb4f6082d8291`, which covers all 50 states. Each state row links the actual USGWD catalog file retained in the release provenance. Dates are Rainfolk acquisition times, not source-observation or publication freshness.

Original dataset: [USGWD, Lin, Miller, Waqar and Marston](https://doi.org/10.4211/hs.8b02895f02c14dd1a749bcc5584a5c55), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Rainfolk prepares and hosts the map artifacts. This is a catalog-level source list, not independent per-record agency or ownership verification.

The contributing organizations and agency links below are transcribed from the publisher's Table S1. They are catalog-level attribution, not a per-record determination. Agency links are recorded publisher references and were not individually checked for current availability. Rainfolk acquisition dates describe downloading the catalog, not the age of well conditions.

Table S1's public/private classification describes how the catalog authors obtained agency data. It does not classify well ownership or grant access to confidential submissions. See [the supplied state notices](US_GROUNDWATER_SOURCE_NOTICES.md), which include unresolved reuse requirements. This source list is not a finding that every condition has been satisfied.
