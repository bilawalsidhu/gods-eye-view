## 14b — Navara

Implemented and self-reviewed without subagents. Points use growing `engine.movers` banks by style, with separate tracked glyphs; orbit rings use `engine.lines` with the same rigid GMST rotation and 0.35 depth-fail alpha. Points retain class colour, distance scaling, outlines and focus alpha. The point contract now accepts outline RGBA; Navara's AA footprint and CPU pick radius include that outline. Sprite/model behaviour is unchanged. The common camera-view adapter was renamed `engineView.js` and reused for CelestialRing; no Navara library entered the initial bundle.

Review caught and fixed: native-only `primitive.id` blocking real Navara picks; a zero initial ring matrix; geo `viewFrom` failing to fill Cesium EntityView's scratch vector; and Cesium AUTO selecting a different high-orbit frame. Native satellite Entities now declare the specified ENU frame and use `engine.camera.follow({native})`, with minimum-range ownership/cleanup. The last two fixes are covered by regression tests. No old code was reformatted.
