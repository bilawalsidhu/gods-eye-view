# Контракты, которые должны выдержать замену планеты

Это спецификация наблюдаемого поведения. Имена методов ниже условны. Сначала подставлять уже существующие операции `GlobeEngine` и renderer contract, расширять их только подтверждённым потребителем.

## Согласованный интерфейс слоя

| Операция | Необходимая гарантия |
|---|---|
| Открыть модель с параметрами источника | Можно выполнить до создания сцены и в тесте Node. Сетевой запрос запускает владелец намерения. Два потребителя получают одну модель/один фид. Открытие каталога само по себе не опрашивает все источники |
| Запросить выборку/описание объекта | Возвращаются данные, свежесть, ID и поколение источника. Аналитика, список и голос получают одну семантику «неизвестно / пусто / есть данные». Возвращаемые значения не содержат DOM, GPU-ресурсов или нативной entity |
| Подключить представление | Входы: модель, операция проекции, часы, возможности, идентификатор попытки. Выход: идемпотентное отключение и сигнал готовности первого кадра. Подписка не теряет события на границе снимка. Обновления неактивного кандидата не захватывают выбор |
| Пользователь отключил слой | Сначала отменить intent и зависимые незавершённые запросы в соответствии с прежним контрактом, затем убрать все текущие подключения. Не оживлять слой поздним ответом после выключения |
| Изменился viewport | Единственный сервис вида публикует нормализованные центр, bbox, zoom/метры на пиксель и время. Триггеры обновления источника учитывают последний запрошенный регион, debounce и давность. Ручной slew, globe flight и resize могут менять LOD, но фиктивный начальный вид кандидата не запускает запрос |
| Разрешить цель | Объект определяется стабильным ключом и, при необходимости, источником и эпохой. Если источник переиспользует ID после истечения истории, признать старую ссылку недействительной. Визуальный индекс экземпляра GPU никогда не сериализуется |

Пример гонки при двух быстрых переключениях: A активен; B подготавливает поколение 17; пользователь выбирает A, затем B поколения 19. Завершение 17 может только освободить ресурсы 17. Оно не вправе снять обработчики A/19, записать заголовок, изменить URL, восстановить фокус или передать право на камеру. При отмене после подготовки, но до первого кадра, назвать причину в результате операции. Источник и принятые ревизии продолжают жить.

## Карта операций адаптера

| Группа | Где уже есть опора | Задача и доказательство |
|---|---|---|
| Поза, кадры, время, управление вводом | `globe/contract.js`, adapter camera/frames/clock/input, `globe/follow.js` | Привязать ввод и захват камеры к одному активному адаптеру. Сопоставить vertical FOV, screen coordinates, roll и отмену flight с помощью одного набора поз и idempotent dispose |
| Pick, проекция и occlusion | GlobeProjector/picker, CPU picks, gpu pick, `data/selectionDispatcher.js` | Разделить выбор объекта/terrain/depth; определить результат при скрытом объекте, прозрачной линии и отсутствии hit. На Retina, высоком pitch и у горизонта сохранять один ID |
| Опора на высоту | `globe/surfaceDetail.js`, terrain, groundFloor/groundSnap/meshFloorSampler | Обязательно указать источник, точность и эллипсоидальную систему. Гора, крыша, море, движущийся самолёт и пропущенный sample — пять различных fixtures |
| Примитивы | `globe/movers.js`, `globe/lines.js`, aircraft renderer, `globe/navara/movers` | Освобождать bank/model handles на detach, не записи модели. При поднятии плотности сохраняются pick ID, видимость трека и лимит batch. Потребитель не должен знать устройство буфера |
| Полигоны, mesh drape, clipping | `layers/installations/render`, native geometry and stencil | Общая геометрия описывает rings/holes; adapter подтверждает terrain-only или drape по всей сцене. Сравнить гору, крышу, стену и отрицательное пространство; не выдавать приближение за точный контур |
| Raster, split, тайлы, права и credits | `maps/*`, recentImagery, weatherImageryHost | Descriptor указывает provider, CRS, охват, дату, opacity, порядок, право/источник. Инспекция direct URL/тайла не получает секрет. Одновременно два изображения во время смены сцены используют корректную границу и видимую атрибуцию |
| Линии взгляда, видео, импорт и screen FX | CCTV, annotations, scopeMask, sky и post-processing | Привязку к глубине и текстурам ограничить адаптером. При отсутствии шейдера UI сообщает, какая операция недоступна; остальные части функции, например монитор камеры, остаются рабочими |
| Рендер по требованию | `renderGovernor.js`, rendererCache, adapter render | Holds принадлежат операции и эпохе; общий application clock переживает park. В скрытой вкладке корректно восстанавливать время, WebGL context и качество. Пустая сцена не рисует постоянно |
| Ресурсы и сеть | карты, источники, провайдеры, media | Логическая сессия может делить разрешённый CPU/HTTP-кэш. GPU-ресурс не переносится между контекстами WebGL. Кэш поверхности зависит от варианта рельефа/тайлов, а не просто lat/lon. Смена двигателя с тем же данными не выдаёт обещаний отсутствия всех сетевых запросов: тайлы/GPU могут потребовать загрузки |

## Какие операции нельзя считать перенесёнными по наличию адаптера

В базовом `src/voice/gevActions.js` есть явный перечень viewer-only команд. Его нужно заменить по командам, по мере прохождения сценариев. `control_scene` требует timeline и bind camera; `annotate_map` и `clear_annotations` — модели аннотаций и подключения draw; `fly_route` и `move_camera` — общего арбитра; `set_context_mode` — независимого расчёта Contacts и сохранения intent слоёв; `control_radio` — независимого плеера; `control_cctv` — владельца потока плюс возможностей геометрии. Для `set_visual_style` и `set_post_processing` проверять поддержанные операции активного адаптера отдельно. Просто удалять команды из списка отказов до реализации запрещает критерий функционального паритета.

## Как подключить следующий движок

1. Зарегистрировать ленивую фабрику сцены и декларацию обязательных/необязательных операций. Довести cold start, pause/resume, потерю контекста и полный dispose до зелёного теста. Код второго SDK не должен оказаться в initial chunk первого.
2. Пройти общий `contractSuite` и безсценовые сценарии. Подключить базовые tiles, рельеф, projection/pick, линии и пакетные маркеры. Переиспользовать общие представления всех слоёв, которым их достаточно.
3. Реализовать специфические графические операции только для оставшихся строк матрицы. Зафиксировать типы и источники fallback, карту недоступности и способ вернуться к рабочему движку при отказе. Схемы UI и API не размножаются по числу SDK.
4. Пройти на новом движке screenshot/identity/нагрузочные gates. Предложение включить его в основной переключатель рассматривается только с результатами. Тот же порядок использовать для будущего обновления SDK без смены бизнес-логики.
