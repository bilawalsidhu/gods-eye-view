# Приёмка слоёв Cesium и Navara

Рабочая ветка `codex/navara`. В каталоге 33 слоя. При выборе другого движка остаются тот же документ, менеджер слоёв и экземпляры всех 33 моделей. Сессия владеет наблюдениями, активными запросами, выбором объектов, часами и проигрывателями. Активный движок получает графику, обработчики ввода и камеру. При возврате приложение использует уже созданный движок. На первом переходе второй движок инициализируется, а последний кадр предыдущего остаётся видимым до первого кадра новой сцены.

## Что проверялось на релизной сборке

Объекты выбираются кликом там, где выбор входит в сценарий. Часть проверок сравнивает пиксели скриншота либо число декодированных кадров. Во всех случаях используются локальные данные или контролируемые ответы источника.

Scene Director проверяется сверх 33 слоёв. Сценарий загружает GeoJSON, изображение PNG и звук WAV, выбирает кликом точку, линию и полигон на обеих планетах и сравнивает цвет наложенного изображения. Сохраняются авторский проект и исходный элемент audio. Двухкадровая сцена со сменой движка во время воспроизведения доходит до штатного завершения. Отдельный тест проверяет отмену ожидающего кадра и освобождение частично созданной графики после отказа нового движка.

## Результат на 3 ноября 2026 года

[Машинный отчёт](acceptance.json) содержит ID слоёв, результаты отдельных сценариев и исходные замеры. Все 28 сценариев из `qa-all-layer-switches.mjs` прошли на одном релизном preview. Они охватывают 33 различных ID и отдельно проверяют Scene Director. Тест `src/app/constructCatalog.test.mjs` сравнивает порядок и идентичность моделей двух рабочих каталогов. В `npm test` прошли 10 615 обычных тестов и 16 проверок в выделенных процессах. Два теста пропущены набором. `check:boundaries`, `build`, `build:panel`, `check:main-chunk` и `git diff --check` прошли. Начальный чанк не включает Three или Navara. Порог размера чанка не проверялся, поскольку файл исторического бюджета отсутствует. Отдельный `format:check` отмечает 117 файлов, оформление которых отличается от Prettier. Старый код массово не переформатировался.

Отдельная проверка на инструментированном dev-сервере подтвердила отрисовку землетрясения на рельефе, перекрытие непрозрачным объектом и возврат в режим без кадров после снятия слоя. Все восемь проверок прошли. На обычной релизной сборке измерен цвет того же типа диска на обеих планетах.

**Время переключения.** Headless Chrome 156 на macOS 27.2, Metal, пустые ключи, два включённых слоя — радио с 750 станциями и землетрясения с фиксированным наблюдением. Замер отсчитывается перед выбором движка и заканчивается после его первого кадра, снятия кадра предыдущей планеты и восстановления состояния. Сюда входит взаимодействие с браузером. В отдельном прогоне из 50 смен первый переход из Navara в Cesium занял 511 мс. По 24 прогретых перехода в каждую сторону дали следующие времена.

| Целевой движок | p50 / p95, мс |
| --- | --- |
| Navara | 86 / 100 |
| Cesium | 54 / 91 |

**Длительная проверка.** За 500 смен сохранились 33 объекта слоёв, выбранная станция, один запуск аудио и один запрос каталога станций. Оба экземпляра движка использовались повторно. На canvas Navara число подписок на потерю и восстановление WebGL-контекста оставалось 3 и 2. После принудительной сборки мусора JS-память составляла 64 МиБ на 50-й смене и 71 МиБ на 500-й. Это измерение JS-кучи всего документа. В него не входит память GPU. Точная форма облаков, освещения и прочих эффектов планеты не является критерием равенства слоёв.

Во время испытаний исправлены три источника удержания ресурсов. Снятый проход Navara освобождает текстуры и подписки на canvas, значки освобождают декодированное изображение и обработчик загрузки, а эффекты и модели удаляют собственную подписку перед кадром. Регрессионные тесты проверяют снятие одного подписчика без остановки другого и завершение загрузки значка во время снятия слоя.

## Как повторить

Собрать приложение и запустить локальный preview из рабочей копии Navara с пустыми `GOOGLE_MAPS_API_KEY` и `CESIUM_ION_TOKEN`. Для браузерных проверок нужны headless Chrome и локальный порт, разрешённый скриптами. Приёмка сохраняет отдельный журнал каждого сценария и `summary.json` в переданный каталог.

```sh
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= npm run build
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= npm run build:panel
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= npm run check:main-chunk
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= npm test
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= npm run check:boundaries
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= node scripts/qa-all-layer-switches.mjs http://127.0.0.1:4208
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= node scripts/qa-radio-engine-switch.mjs http://127.0.0.1:4208 --soak
GOOGLE_MAPS_API_KEY= CESIUM_ION_TOKEN= node scripts/qa-radio-engine-switch.mjs http://127.0.0.1:4208 --soak --swaps=500
```

Платные Google Tiles и Cesium ion исключены из браузерного прогона. Для Google Street View используются тесты провайдера с имитацией SDK. Для Local ADS-B используется приёмник-фикстура. Время отклика живых внешних сервисов и реальное USB-оборудование этим прогоном не измеряются.
