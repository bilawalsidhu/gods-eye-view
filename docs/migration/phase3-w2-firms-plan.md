Default sharpening is a separate unresolved consumer requirement: native FIRMS glows participate in its sharpen stage, whereas current Navara movers render afterward. Raw-alpha agreement does not establish default-look glow parity. Add a minimal explicit per-set pre-sharpen stage only when wiring the actual FIRMS bank; retain existing W1 placement, public SDK descriptors, lazy resources and normal real-input picking. Prove default pixels and lifecycle before accepting it.

Heatmap bounds will use true geodetic parallels. For ECEF point(x,y,z), rho=hypot(x,y), WGS84 eccentricity squared e2 and N(phi)=a/sqrt(1-e2*sin(phi)^2), a constant geodetic latitude at arbitrary height satisfies `z*cos(phi)-rho*sin(phi)+e2*N(phi)*sin(phi)*cos(phi)=0`. Longitude boundaries are planes. A draft calculation agrees with public RectangleGeometry across56 one/two-degree cases,562 vertices and2688 boundary-height samples (−100km through12km), within1.4e-9m. This establishes the formula only; shader precision, candidate bounds, actual native raster, surface masking and performance remain unverified. Evaluate spatial derivatives before divergent candidate branches, as established by earthquakes.

The sprite atlas retains the actual16..56px PNG dimensions in each UV cell, with padded neighboring cells and per-instance scale against a56px base. Padding every glyph to56px geometry would incorrectly enlarge CPU pick bounds. Batch updates and image decode completions must preserve source order and revalidate the active generation after disable/destroy.

Positive raster counts missed visible yellow strips at the globe silhouette. The new geometry QA captures actual native rectangle coordinates, projects conservative0..12km bounds on each engine, keeps the existing2px limit and requires zero changed pixels outside them. For pixels intersecting multiple edges, clip the same pixel square by all four linearized halfspaces and use its actual covered area; fully inside and single-edge pixels retain the fast path.
