## Gate 1 — why EXIT BLOCKED (secret-free)

Gate 1 requires the branch to be observed on a real Vercel function runtime **and** a live contract run against it. On 2026-09-17 neither was possible:

1. **No God's Eye deployment exists.** The Vercel account (user `navnit-5790`, team `schoolhack-web-team`) has no project linked to `bilawalsidhu/gods-eye-view` and none named `gods-eye-view` / `gods-eye-view-ondemand-serverless` (project list inspected: `ondemand-hq`, `airev-ondemand-deck`, `ondemand-agent`, `rilian-airev-ondemand-deck`, `ondemand-eand-spatial`, `ondemand-eand-spatial-jyxd`, `airev-ondemand-investor-deck`, `on-demand-ai-investments`).
2. **The fallback host is a different application.** Per the resolution rule, `finalProductionUrl` fell to the READY preview alias `https://ondemand-eand-spatial-opal.vercel.app` (project `ondemand-eand-spatial`, `prj_VbHbEhFSDFkdXCqlq8XqONoFWQHO`, deployment `dpl_FKoHEVctqpLzNMaHV9sSRdmzcrw6`, commit `b8cdcf50` of `mk42-ai/ondemand-eand-spatial`) because the production target (`dpl_7CAoCxdEQRQ7W12mzwz4iGKDK4V9`, commit `e799775a`) is **BLOCKED** and its alias answers `404 DEPLOYMENT_NOT_FOUND`. That host serves another Vite app; `GET /api/ondemand/health` there returns Vercel's platform `404 NOT_FOUND` (`x-vercel-error: NOT_FOUND`) at 2026-09-17T08:12:13Z — it is **not** the God's Eye serverless build.
3. **A deployment could not be created from this workspace.** `vercel link` / `vercel deploy` / `vercel env pull` are refused by the platform guardrail (`vercel: BLOCKED by platform policy — the Vercel CLI is not available in this environment`, exit 126, 2026-09-17T08:12:26Z) and workarounds are prohibited.
4. **Contract test — neither mode could run live.** `env-pull` mode: refused as above (and `ONDEMAND_API_KEY` is a `sensitive` variable, which Vercel never returns via pull). `proxy` mode: forced, but `finalProductionUrl/api/ondemand/*` does not exist (404), so step 1 fails and steps 2–9 are dependency-skipped — recorded verbatim in `contract-baseline.json` (`mode: "proxy"`).

The branch itself is green (4,144 upstream unit tests, 30 serverless + 93 ondemand tests, boundaries, prettier, production build) and its runtime behaviour is proven only in an ephemeral sandbox emulator (`docs/audit/deployment-verification.md` §1–3), which does not satisfy the Gate 1 exit criterion.

### Gate 1 exit requirements (what closes it)

- Deploy `ondemand-serverless` to a Vercel project (see `DEPLOYMENT_REPORT` hand-off, Option A/B) and re-run `node scripts/ondemand-contract-test.mjs --mode proxy --proxy-base <url>/api/ondemand --json-out docs/ondemand-workflows/contract-baseline.json`.
- Health must read `configured:true` with chat/media/workflow `healthy` (speech `degraded` is by design — no read-only Services probe is documented).
