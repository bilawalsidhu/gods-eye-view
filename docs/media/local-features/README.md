# Synthetic UI examples

These five screenshots were captured in a separate browser profile from an
isolated local app. The camera artwork and metadata are invented. Location is
an invented test coordinate; OpenAI capability and answers are mocked. No real
camera footage, GPS fix, API credential, person, plate, deployment identity or
infrastructure dataset appears here.

- [Phone menu](mobile-menu.png): map-first sections and Back to map.
- [Phone camera](mobile-camera.png): Refresh, Fullscreen, Minimize and Close.
- [Phone fullscreen](mobile-fullscreen.png): Back returns, source credits remain.
- [Desktop expansion](desktop-camera-expanded.png): Restore/Escape retains the
  existing playing surface.
- [Snapshot/Q&A](snapshot-sol-high.png): original image, annotations and explicit
  send confirmation. The shown capability is a test fixture, not live inference.

The original SVG scene is in `public/test-fixtures/synthetic-camera.svg` under
the project's MIT license. Interface code retains Bilawal Sidhu's MIT copyright.
Cesium/other dependencies and logos retain their existing notices. Offline map
requests used Cesium's bundled Natural Earth texture (public domain); the
software renderer's blank background is not a map-quality demonstration. These
screenshots illustrate controls, not the quality or availability of live feeds.
