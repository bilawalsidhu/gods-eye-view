# Rust / WASM Infrastructure

This directory contains Rust crates compiled to WebAssembly for performance-critical
operations in God's Eye View.

## Packages

### firms-renderer

WASM heatmap renderer for NASA FIRMS fire detections (100k+ points).

**Build:**
```bash
cd rust/firms-renderer
wasm-pack build --target web --out-dir ../../public/wasm/firms-renderer
```

**Requirements:**
- Rust 1.97+
- wasm-pack 0.14+

**Notes:**
- `wasm-opt` is disabled in release builds due to a bulk-memory compatibility issue
  with the installed wasm-opt binary. Size optimization is handled by the Rust
  profile settings (`opt-level = "z"`, `lto = true`, `strip = true`).
- The WASM is served from `public/wasm/firms-renderer/` and imported by
  `src/data/firmsHeatmap.js` via dynamic `import()`.

**Files:**
- `firms_renderer.js` — JS bindings (auto-generated by wasm-bindgen)
- `firms_renderer_bg.wasm` — compiled WASM binary
- `firms_renderer.d.ts` — TypeScript declarations
