Source components from the shadcn-vue New York v4 registry:
https://www.shadcn-vue.com/r/styles/new-york-v4/{component}.json

Local imports use explicit paths. Unused registry components are omitted; only controls used by this console are vendored. Command accepts shouldFilter=false for app-owned live search; a prevented item select preserves the query during asynchronous place search. Components retain their upstream styles and Reka behavior. Tailwind utilities are scoped to these components and their consumers; preflight is not installed globally.
