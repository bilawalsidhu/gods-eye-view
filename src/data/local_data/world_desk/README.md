# World Desk historical catalog

Bundled major recorded events from 3000 BCE to the present, used by the
World News / World Desk timeline.

This is **not** a complete newscast. Dates for prophets and some early
rulers are traditional. Coordinates are approximate. Live coverage is a
separate GDELT feed.

Attribution: standard public chronology (textbook / encyclopedic consensus).
The MIT code license does not make these events an authoritative record.
